# PR screenshots

Before and after screenshots for Orchard Core bug-fix pull requests, referenced from the PR descriptions.

Each folder is named after a pull request of OrchardCMS/OrchardCore and holds `before.png` (the bug, on `main`) and
`after.png` (the same steps with the fix), plus extra images where one is not enough. They were taken on a throwaway
local site set up with the Blog recipe, with fake data only.
